# teshnizi/tap

Homebrew tap for two macOS menu bar apps.

## BudDial

[BudDial](https://github.com/teshnizi/BudDial): type with your voice by holding an AirPod.

```sh
brew install --cask teshnizi/tap/buddial
```

Upgrade with `brew upgrade --cask buddial`. Remove with `brew uninstall --cask buddial`, or `brew uninstall --zap --cask buddial` to also delete its settings and speech model.

## RestBreak

[RestBreak](https://github.com/teshnizi/RestBreak): break reminders for your eyes, neck and posture that hold during calls.

```sh
brew install --cask teshnizi/tap/restbreak
```

Upgrade with `brew upgrade --cask restbreak`. Remove with `brew uninstall --cask restbreak`, or `brew uninstall --zap --cask restbreak` to also delete its settings and stats.

## Not notarized

Neither app is notarized by Apple, so each cask clears macOS's quarantine flag after installing. Without that, the first launch stops at "Apple could not verify" the app. Each cask is generated by `tools/publish_cask.sh` in its app's repository.
