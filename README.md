# teshnizi/tap

Homebrew tap for [BudDial](https://github.com/teshnizi/BudDial): type with your voice by holding an AirPod.

```sh
brew install --cask teshnizi/tap/buddial
```

Upgrade with `brew upgrade --cask buddial`. Remove with `brew uninstall --cask buddial`, or `brew uninstall --zap --cask buddial` to also delete its settings and speech model.

BudDial is signed but not notarized by Apple, so this cask clears macOS's quarantine flag after installing. Without that, the first launch stops at "Apple could not verify BudDial". The cask is generated by `tools/publish_cask.sh` in the BudDial repository.
